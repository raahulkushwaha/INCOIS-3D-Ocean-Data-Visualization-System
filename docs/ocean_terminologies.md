# Ocean Terminology — Quick Reference

## 🌊 Basic Ocean Terms

| Term | One-line definition |
|---|---|
| **Ocean** | A large body of saltwater covering most of Earth's surface. |
| **Sea** | A smaller part of an ocean, usually partly enclosed by land. |
| **Seawater** | Water containing dissolved salts and other substances found in the ocean. |
| **Ocean Depth** | The vertical distance from the sea surface to the seafloor. |
| **Water Column** | The vertical section of ocean water from the surface down to the seabed. |
| **Sea Surface** | The upper boundary of the ocean that interacts with the atmosphere. |
| **Bathymetry** | The measurement and mapping of underwater depth and seafloor shape. |
| **Ocean Basin** | A large depression in Earth's crust occupied by an ocean. |

## 🌡️ Physical Ocean Variables

| Term | One-line definition |
|---|---|
| **Temperature** | How hot or cold seawater is, usually measured in °C. |
| **Salinity** | The amount of dissolved salt in seawater, commonly measured in PSU. |
| **Density** | The mass of seawater per unit volume, mainly controlled by temperature and salinity. |
| **Pressure** | The force exerted by the water above a point, which increases with depth. |
| **Current** | The continuous movement of seawater in a particular direction. |
| **Current Speed** | How fast ocean water is moving, usually measured in m/s. |
| **Current Direction** | The direction toward which an ocean current is flowing. |
| **Wave** | A moving disturbance that transfers energy through the ocean, usually generated by wind, tides, or other forces. |
| **Sea Level** | The height of the ocean surface relative to a reference level. |
| **Sea Surface Temperature (SST)** | The temperature of seawater near the ocean surface. |

## 📐 3D / Data Terms

| Term | One-line definition |
|---|---|
| **Latitude** | Position north or south of the Equator, measured in degrees. |
| **Longitude** | Position east or west of the Prime Meridian, measured in degrees. |
| **Depth Level** | A specific vertical position below the ocean surface, such as 50 m or 500 m. |
| **Grid** | A set of regularly spaced latitude-longitude-depth points where model values are calculated. |
| **Grid Cell** | A small region of the model grid containing calculated ocean values. |
| **Spatial Resolution** | The geographic size represented by each model grid cell. |
| **Temporal Resolution** | The time interval between consecutive model outputs or observations. |
| **3D Field** | A variable such as temperature represented across latitude, longitude, and depth. |
| **Volume** | The entire 3D region of ocean represented by a dataset. |
| **Depth Slice** | A horizontal layer of the ocean extracted at a particular depth. |
| **Vertical Slice** | A vertical cross-section showing how an ocean variable changes with depth and distance. |
| **Isosurface** | A 3D surface connecting locations that have the same value of a variable. |
| **Vector** | An arrow representing both the magnitude and direction of something, such as ocean current. |
| **Scalar** | A variable represented by a single value at each location, such as temperature or salinity. |
| **Colorbar** | A visual scale that maps colors to numerical values. |
| **Colormap** | The color scheme used to represent different data values. |
| **Vertical Exaggeration** | Artificially increasing displayed ocean depth to make vertical structures easier to see. |

## 🤿 Observation & Instrument Terms

| Term | One-line definition |
|---|---|
| **Argo Float** | An autonomous instrument that drifts through the ocean and measures variables such as temperature and salinity at different depths. |
| **Glider** | An autonomous underwater vehicle that moves through the ocean while collecting measurements along a path. |
| **CTD** | An instrument that measures Conductivity, Temperature, and Depth to characterize seawater properties. |
| **BGC** | Biogeochemical measurements describing biological and chemical properties of the ocean, such as oxygen and chlorophyll. |
| **ADCP** | Acoustic Doppler Current Profiler that measures ocean-current speed and direction at different depths. |
| **Mooring** | An instrument platform anchored to the seafloor that continuously records ocean conditions. |
| **Drifter** | A floating instrument that moves with ocean currents while recording observations. |
| **Profile** | Measurements of one or more ocean variables as a function of depth. |
| **Observation** | A measurement of the real ocean collected by an instrument or sensor. |
| **Observation Track** | The geographic path followed by an observing platform such as a glider or drifter. |

## 🧮 Ocean Model Terms

| Term | One-line definition |
|---|---|
| **Ocean Model** | A computer-based mathematical representation used to simulate ocean conditions. |
| **Model Output** | Numerical values produced by an ocean model for specific locations, depths, and times. |
| **Forecast** | A model-based prediction of future ocean conditions. |
| **Analysis** | The best estimate of the current ocean state using available observations and models. |
| **Data Assimilation** | Combining observations with a model to improve the estimated ocean state. |
| **Model Resolution** | The size of the spatial and temporal details represented by an ocean model. |
| **Model-Observation Comparison** | Comparing simulated model values with actual measurements to evaluate model performance. |
| **Bias** | The systematic difference between model predictions and observations. |
| **Anomaly** | The difference between an observed/model value and a reference or expected value. |
| **Interpolation** | Estimating values at locations where direct measurements are unavailable. |

## 🌿 Biological & Chemical Terms

| Term | One-line definition |
|---|---|
| **Chlorophyll-a** | A pigment used by phytoplankton and commonly used as an indicator of their abundance. |
| **Phytoplankton** | Microscopic marine organisms that perform photosynthesis and form the base of many ocean food webs. |
| **Dissolved Oxygen (DO)** | The amount of oxygen dissolved in seawater and available to marine organisms. |
| **Nutrients** | Dissolved substances such as nitrate and phosphate that support marine biological growth. |
| **Biogeochemistry** | The study of how biological, chemical, and physical processes interact in the ocean. |
| **Carbon Cycle** | The movement of carbon between the atmosphere, ocean, organisms, and other parts of Earth. |

## 🌊 Important Ocean Phenomena

| Term | One-line definition |
|---|---|
| **Upwelling** | The movement of deeper, colder, nutrient-rich water toward the surface. |
| **Downwelling** | The movement of surface water toward deeper parts of the ocean. |
| **Thermocline** | A layer where seawater temperature changes rapidly with depth. |
| **Halocline** | A layer where salinity changes rapidly with depth. |
| **Pycnocline** | A layer where seawater density changes rapidly with depth. |
| **Stratification** | The layering of ocean water caused by differences in density. |
| **Mixing** | The process by which ocean water with different properties becomes distributed together. |
| **Eddy** | A rotating body of ocean water that can transport heat, salt, nutrients, and other properties. |
| **Front** | A boundary between water masses with significantly different properties. |
| **Water Mass** | A large body of seawater with characteristic temperature and salinity properties. |
| **Tide** | The periodic rise and fall of sea level mainly caused by the gravitational effects of the Moon and Sun. |
| **Monsoon** | A seasonal reversal of winds that strongly influences ocean conditions around the Indian Ocean. |
| **Upwelling Zone** | A region where deeper water rises toward the surface, often bringing nutrients upward. |

## 🗂️ Data & File Terms

| Term | One-line definition |
|---|---|
| **NetCDF** | A scientific data format designed for storing multidimensional data such as time × depth × latitude × longitude. |
| **CF Conventions** | Standard rules for describing climate and oceanographic data inside formats such as NetCDF. |
| **xarray** | A Python library for working with labeled multidimensional scientific datasets. |
| **OPeNDAP** | A protocol that allows remote access to scientific datasets without downloading the entire file. |
| **WMS** | An OGC standard for requesting georeferenced map images from a server. |
| **WCS** | An OGC standard for accessing geospatial coverage data such as scientific raster fields. |
| **OGC** | An organization that develops open standards for geospatial data and services. |
| **Metadata** | Information describing a dataset, such as its variables, units, dimensions, source, and time range. |
| **Missing Value** | A location or time where no valid measurement exists in the dataset. |
| **Time Step** | One specific point in the dataset's time sequence, such as 12:00 UTC. |

## ⭐ The 10 Terms to Understand First

1. **Water Column** → Ocean from surface to seabed.
2. **Temperature** → How hot or cold the water is.
3. **Salinity** → How much salt is dissolved in the water.
4. **Density** → How heavy the seawater is for its volume.
5. **Current** → Movement of ocean water.
6. **Argo Float** → Autonomous instrument measuring ocean profiles.
7. **Glider** → Underwater vehicle collecting measurements along a path.
8. **Ocean Model** → Computer simulation of ocean conditions.
9. **Depth Slice** → Horizontal view of the ocean at a selected depth.
10. **Isosurface** → 3D surface connecting points with the same value.

## 🧠 Core Mental Model

> **Ocean data = Variable + Location + Depth + Time**

For example:

> **Temperature = 27.4°C at (15°N, 72°E), 100 m depth, at 12:00 UTC.**

The entire 3D visualization system is built around understanding ocean data across four dimensions:

**Latitude × Longitude × Depth × Time**
